# Hachathongame (Cosmic Maze)

A cat races through four increasingly challenging levels, jumping over hazards and collecting fish. Along the way, it flips gravity, freezes moving saws, and switches between dimensions to reach the finish.

## ▶️ Play in your browser

**[Play Cosmic Maze on itch.io](https://omkardevalkar.itch.io/cosmic-maze)**

## Controls

| Key | Action |
|-----|--------|
| A / D | Move |
| Space | Jump |
| G | Flip gravity (on ground) |
| R | Restart |

## Built with

- Godot 4.7
- Exported to HTML5 / WebAssembly and hosted on itch.io
